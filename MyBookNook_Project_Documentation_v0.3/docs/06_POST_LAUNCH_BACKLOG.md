# Post-Launch Backlog

v1.0 prioritizes collection integrity, privacy, profiles, friends,
lending, notifications, barcode-assisted entry, and PWA usability. The
following features remain candidates for later releases.

## Social Expansion

-   Activity feed
-   Likes/reactions
-   Review comments
-   Direct messaging
-   Groups
-   Book clubs
-   Follower model in addition to mutual friends
-   Friend recommendations
-   Collection comparison
-   Shared-interest discovery
-   Trending books/records

## Recommendations

Possible recommendation inputs:

-   Friends' collections
-   Similar collections
-   Ratings
-   Shelves/tags
-   Reading/listening history

Recommendations should provide understandable reasons rather than
appearing arbitrary.

## Reading and Collection Engagement

-   Reading goals
-   Annual challenges
-   Pages/books completed
-   Advanced statistics
-   Collection milestones
-   Richer reading history
-   Expanded collection analytics

## Notifications

Possible expansion:

-   Social-feed activity
-   Review comments
-   Group/book-club activity
-   Recommendation notifications
-   Additional delivery channels

High-volume optional activity should not become excessive push traffic.

## Monetization

Possible additions:

-   Ad-free supporter tier
-   Cosmetic/convenience supporter benefits
-   Additional monetization that does not restrict core collection
    functionality

## Native Applications

Native Android/iOS apps can be reconsidered if PWA limitations or user
demand justify the additional development, maintenance, and distribution
cost.

## Offline Support

Full offline collection access, mutation queues, and synchronization can
be explored after the online-first PWA is stable.

## Advanced Vinyl Modeling

If collector demand requires it:

-   Pressing plants
-   Matrix/runout data
-   Vinyl color variants
-   Country/territory releases
-   Detailed format/speed/size
-   Release-level provenance

v1 should not attempt to reproduce the full complexity of specialist
record databases unless real usage justifies it.
