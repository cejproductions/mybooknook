# MyBookNook Project Documentation

**Planning baseline:** v0.2  
**Purpose:** Consolidated documentation for the current development build, approved v1.0 scope, planned additions, architecture, data model direction, and launch roadmap.

MyBookNook is a web-first personal collection and social platform for books and vinyl records. The current application already has a working React/TypeScript frontend, FastAPI backend, PostgreSQL database, JWT authentication, and basic collection management.

## Documents

1. `docs/01_CURRENT_BUILD.md` - What is implemented and working now.
2. `docs/02_V1_PRODUCT_SPEC.md` - Approved functionality for the v1.0 launch.
3. `docs/03_SYSTEM_ARCHITECTURE.md` - Current and planned production architecture.
4. `docs/04_DATA_MODEL_PLAN.md` - Domain entities, ownership of data, privacy, and relationships.
5. `docs/05_DEVELOPMENT_ROADMAP.md` - Recommended implementation sequence.
6. `docs/06_POST_LAUNCH_BACKLOG.md` - Features intentionally deferred until after v1.0.
7. `docs/07_DECISIONS_AND_OPEN_ITEMS.md` - Product decisions already made and remaining details to settle.

This package is a planning/documentation snapshot. It does not replace the application source code.
