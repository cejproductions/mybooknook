# Post-Launch Backlog

v1.0 focuses on a strong collection foundation. These features should be evaluated after observing real usage.

## Social Expansion

Potential additions:

- Activity feed
- Likes/reactions
- Review comments
- Direct messaging
- Groups
- Book clubs
- Following model in addition to friends
- Friend recommendations
- Collection comparison
- Shared-interest discovery
- Trending books/records

## Recommendations

Possible future recommendation sources:

- Friends' collections
- Similar collections
- Ratings
- Genres/tags
- Reading/listening history

Recommendation design should be transparent enough that users understand why something is being suggested.

## Reading / Collection Engagement

Potential additions:

- Reading goals
- Annual challenges
- Pages/books completed
- Advanced statistics
- Collection milestones
- Richer reading history

## Notifications

Potential expansion:

- Social feed activity
- Review comments
- Group/book-club activity
- Recommendation notifications
- Additional notification delivery channels

Avoid turning optional social activity into excessive push traffic.

## Monetization

Potential additions:

- Ad-free supporter tier
- Cosmetic/convenience supporter benefits
- Additional monetization only if it does not undermine core collection functionality

## Native Applications

A native Android/iOS application can be reconsidered if PWA limitations or user demand justify the additional maintenance and distribution costs.

## Offline Support

Full offline collection access and synchronization can be explored after the online-first PWA is stable.
